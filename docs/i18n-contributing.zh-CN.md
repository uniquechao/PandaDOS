# 本地化贡献指南

[English](i18n-contributing.md)

英语（`en`）是源语言和运行时最终回退语言。首发语言为 `en`、`zh-Hans`、`zh-Hant`、`ja`、`ko`、`es`、`fr`、`de`、`pt-BR`、`ru`。

产品控制的界面、按钮、占位提示、校验与错误、确认框、通知、邮件和飞书卡片必须使用语义化消息键。用户输入的 issue、代码、终端输出、Git 内容、文件路径、命令、协议标记和已有聊天记录一律保持原文。

请遵循[本地化术语与语气指南](../shared/i18n/glossary.zh-CN.md)。每个发布语言都必须完成人工术语与语气复核；与英语完全相同的值只能是已认可的技术术语或标识符。

动态值使用 ICU 参数，所有语言必须保留完全相同的参数名。日期、数字、相对时间和时区统一使用共享格式化器，不拼接本地化片段。账户语言与时区优先；浏览器检测只用于首次默认值，最终回退为英语。

中文用户的 AI 系统提示词使用中文；其他语言使用英文内部提示词，并附带用户所选语言的输出约束。澄清、摘要和审批说明使用用户语言，引用的技术材料保持原文。

提交前运行：

```bash
bun run check-i18n
bun run typecheck
bun test
bun run build-ui
```

`check-i18n` 检查目录键、ICU 参数与语法、语言匹配、格式化和伪本地化。开发界面时可用 `pseudoCatalog()` 暴露截断和硬编码。`shared/i18n/guard.ts` 的 TypeScript 扫描器可加入定向 CI，品牌名和协议标记应放入明确白名单。

公开用户文档默认英语，并提供同级 `*.zh-CN.md` 中文版本。内部设计与实施计划使用中文，只能放在被忽略的本地 `.private/` 目录，绝不能提交到公开分支。
