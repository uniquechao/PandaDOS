# PandaDOS v0.2.2

## 版本亮点

- 新增项目级可复用 Issue 工作流，支持版本化模板、条件分支、受限循环、并行执行与冲突恢复。
- 终端历史滚动改为直接控制 tmux copy-mode，触控板、滚轮和翻页按钮不再被误当成上下方向键。
- Codex、Claude Code 与 tmux 项目导入统一支持 `issue` 和 `chat` 两种项目类型。

## 新功能

- 工作流模板支持编辑、校验、复制、删除与版本快照；创建 Issue 时可预览并选择高级流程。
- 工作流节点可使用独立 Agent 会话、自然语言分支和并行 worktree，运行态页面会展示路由、汇合、冲突与恢复状态。
- 项目导入弹窗新增类型选择和模式说明；导入 Agent 历史时仍保留可继续的原生对话。

## 改进

- 设计工作台的新建任务弹窗统一为 PandaDOS 视觉体系，完善 Agent 选择、键盘焦点、44px 触控区与窄屏布局。
- Issue 计划列表的子任务编辑入口更醒目，同时保留原有权限与保存流程。
- 执行进度说明浮层支持双轴避让、上下自动翻转、Escape 关闭及鼠标、触摸和键盘操作。

## 修复

- 修复 Codex 新会话在同一工作目录中可能误绑到旧 rollout 记录，导致“对话”与原生终端内容不一致的问题。
- 修复 tmux 备用缓冲区中滚轮和触控板操作被转换为方向键的问题，并保持普通缓冲区原有回滚行为。
- 修复执行进度全文浮层被压窄或越出可视区域的问题。

## 升级说明

- 本版本包含数据库结构更新；升级前请停止正在执行的任务并备份数据库、运行目录和执行机密钥。
- 运行 `bun install --frozen-lockfile`、`bun run check-i18n`、`bun run typecheck`、`bun test` 和 `bun run build-ui`，重启服务后检查 `/healthz`。
