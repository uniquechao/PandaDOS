# PandaDOS v0.2.2

## Highlights / 版本亮点

- **English:** Added reusable project-level Issue workflows with versioned templates, conditional branches, bounded loops, parallel execution, and conflict recovery.<br>
  **中文：**新增项目级可复用 Issue 工作流，支持版本化模板、条件分支、受限循环、并行执行与冲突恢复。
- **English:** Terminal history scrolling now controls tmux copy-mode directly, so trackpad gestures, mouse-wheel input, and page buttons are no longer mistaken for arrow-key input.<br>
  **中文：**终端历史滚动改为直接控制 tmux copy-mode，触控板、滚轮和翻页按钮不再被误当成上下方向键。
- **English:** Codex, Claude Code, and tmux project imports now consistently support both `issue` and `chat` project types.<br>
  **中文：**Codex、Claude Code 与 tmux 项目导入统一支持 `issue` 和 `chat` 两种项目类型。

## New Features / 新功能

- **English:** Workflow templates can now be edited, validated, copied, deleted, and saved as versioned snapshots; advanced workflows can be previewed and selected when creating an Issue.<br>
  **中文：**工作流模板支持编辑、校验、复制、删除与版本快照；创建 Issue 时可预览并选择高级流程。
- **English:** Workflow nodes can use isolated Agent sessions, natural-language branches, and parallel worktrees, while runtime views expose routing, joins, conflicts, and recovery states.<br>
  **中文：**工作流节点可使用独立 Agent 会话、自然语言分支和并行 worktree，运行态页面会展示路由、汇合、冲突与恢复状态。
- **English:** The project import dialog now includes project-type selection and mode guidance, while imported Agent histories retain their resumable native conversations.<br>
  **中文：**项目导入弹窗新增类型选择和模式说明；导入 Agent 历史时仍保留可继续的原生对话。

## Improvements / 改进

- **English:** The Design workspace's new-task dialog now follows the PandaDOS visual system, with improved Agent selection, keyboard focus, 44px touch targets, and narrow-screen layouts.<br>
  **中文：**设计工作台的新建任务弹窗统一为 PandaDOS 视觉体系，完善 Agent 选择、键盘焦点、44px 触控区与窄屏布局。
- **English:** Subtask editing is easier to find in the Issue plan list while preserving the existing authorization and save flows.<br>
  **中文：**Issue 计划列表的子任务编辑入口更醒目，同时保留原有权限与保存流程。
- **English:** Execution-progress detail popovers now avoid both viewport axes, flip vertically when needed, close with Escape, and support mouse, touch, and keyboard input.<br>
  **中文：**执行进度说明浮层支持双轴避让、上下自动翻转、Escape 关闭及鼠标、触摸和键盘操作。

## Fixes / 修复

- **English:** Fixed new Codex sessions in the same working directory sometimes attaching to an older rollout record, causing the conversation view to disagree with native terminal content.<br>
  **中文：**修复 Codex 新会话在同一工作目录中可能误绑到旧 rollout 记录，导致“对话”与原生终端内容不一致的问题。
- **English:** Fixed mouse-wheel and trackpad input being converted into arrow keys in tmux alternate-screen buffers while preserving normal scrollback behavior in regular buffers.<br>
  **中文：**修复 tmux 备用缓冲区中滚轮和触控板操作被转换为方向键的问题，并保持普通缓冲区原有回滚行为。
- **English:** Fixed execution-progress full-text popovers being squeezed too narrow or extending beyond the viewport.<br>
  **中文：**修复执行进度全文浮层被压窄或越出可视区域的问题。

## Upgrade Notes / 升级说明

- **English:** This release includes database schema updates. Before upgrading, stop active tasks and back up the database, runtime directory, and executor keys.<br>
  **中文：**本版本包含数据库结构更新；升级前请停止正在执行的任务并备份数据库、运行目录和执行机密钥。
- **English:** Run `bun install --frozen-lockfile`, `bun run check-i18n`, `bun run typecheck`, `bun test`, and `bun run build-ui`; restart the service and then verify `/healthz`.<br>
  **中文：**运行 `bun install --frozen-lockfile`、`bun run check-i18n`、`bun run typecheck`、`bun test` 和 `bun run build-ui`，重启服务后检查 `/healthz`。
