# PandaDOS v0.2.0

## 版本亮点

- 产品品牌与运行时标识统一为 PandaDOS、`panda`、`PANDA_*` 和 `~/.panda`，侧边栏直接显示当前版本号。
- 项目设置重构为更紧凑的控制台：基本信息、Git 仓库与执行机、Issue 订阅、成员、模块各自独立，常用信息在首屏即可查看和维护。
- GitHub 与 GitLab Issue 接入形成完整闭环，可从仓库 remote 自动识别平台和实例，并在 Issue 列表中获取、筛选、编辑、忽略或导入外部 Issue。

## 新功能

- 支持导入当前项目的 Claude Code / Codex 原生历史会话，保留原生会话标识和标题，并自动排除由 PandaDOS Issue 引擎创建的会话。
- 项目基本信息支持从 README 手动更新简介；项目配置页可查看绑定目录、Git remote、执行机能力、成员统计和详细模块列表。
- Git 工作区和 Issue 改动页支持图片新增、修改、重命名及删除场景的前后版本预览，并提供原图查看与下载。
- 全站提供十种语言、IANA 时区偏好、ICU 复数规则和可见文案静态门禁；通知与审批卡按接收者的语言及时区渲染。

## 改进

- Issue 工作台把外部 Issue 导入入口移到列表顶部，精简导航和项目配置字段，并统一桌面端、移动端的紧凑布局与全局配色。
- 未派发子任务可直接编辑；执行页对话日志支持自动补拉更早记录，重连后仍保持当前 Issue 的完整上下文。
- 侧栏、登录页和浏览器元信息移除营销 slogan，仅保留 PandaDOS 品牌与技术版本信息。
- 移动端终端支持单指触摸滚动；执行机目录、Agent 能力和 Git 仓库信息的展示与校验更完整。

## 修复

- 修复子任务保存失败时错误提示不准确的问题，补齐文本校验、子任务不存在和已派发冲突等稳定错误映射。
- 修复 Git 与 Issue 中二进制图片只能显示占位信息、无法查看实际差异的问题。
- 修复切换项目时短暂显示旧 Issue 列表、执行中状态环偏移，以及部分非英语界面回退到固定语言的问题。

## 升级说明

- 升级前请停止正在执行的任务，并备份数据库、运行目录和执行机密钥。
- 从 v0.1.x 升级时，请把部署配置从 `MANDO_*` / `~/.mando` / `mando` 更新为 `PANDA_*` / `~/.panda` / `panda`；确认新服务读取到数据库与密钥后，再处理旧运行目录。
- 运行 `bun install --frozen-lockfile`、`bun run check-i18n`、`bun run typecheck`、`bun test` 和 `bun run build-ui`，重启服务后检查 `/healthz`。
