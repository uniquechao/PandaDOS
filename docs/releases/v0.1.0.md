# Mando AI v0.1.0

这是 Mando AI 的首个公开版本。它把 Issue 队列、Claude Code / Codex、tmux 会话和
浏览器工作台连接为一套可持续运行的开发代理协作流程。

## 版本亮点

- **Issue 驱动的执行闭环**：支持需求澄清、规划、执行、验证、人工审批和结果回写，
  并在服务重启后恢复仍需继续推进的任务。
- **双代理与持久会话**：项目可以选择 Claude Code 或 Codex，复用逻辑会话，并在
  代理进程异常退出时进行存活检查和受控恢复。
- **浏览器工作台**：集中查看对话、原生终端、文件、图片、Git 提交与工作区改动；
  桌面端和移动端均可参与任务处理。
- **分级自动批准**：谨慎、均衡、自动三种级别可按任务选择；高风险操作仍需要人工
  确认，审批界面会说明操作内容与原因。
- **项目与团队协作**：支持多项目、多成员、模块化 Issue 管理、项目摘要、通知订阅
  和常驻项目对话。

## 新功能

- 提供项目看板、Issue 详情、执行进度、状态筛选和搜索入口。
- 支持在创建 Issue 时选择代理、工作类型、目标分支和批准级别。
- 支持项目对话与 Issue 对话，显示当前代理模型并保留消息历史。
- 支持本机与 SSH 执行机，可在网页中查看和接管原生终端。
- 提供文件树、文件预览、图片上传与灯箱预览。
- 提供 Git 图谱、提交详情、文件差异、工作区改动和 AI 辅助解读。
- 提供项目成员、用户统计、模块整理、项目归档与删除等管理能力。

## 改进与修复

- 代理 CLI 不存在或会话无法恢复时会明确阻塞任务，避免在 shell 中重复注入或静默
  等待。
- 修复对话历史丢失、执行消息不同步和共享模块对话混杂的问题。
- 改进澄清问题的识别、完整展示与弹窗交互。
- 优化 Issue、模块、成员、终端和 Git 图谱在桌面端与窄屏设备上的布局。
- 修复截图预览层级、前端资源加载、终端触摸滚动和 macOS 本机终端适配问题。

## 安装与升级

首次安装：

```bash
bun install --frozen-lockfile
bun run build-ui
bun run start
```

从内部或开发版本升级时，建议先备份 SQLite 数据库和运行配置，再更新代码并重新执行
依赖安装与前端构建。服务启动时会自动运行数据库迁移。

部署前请阅读仓库中的 `DEPLOY.md`，并确认 `.env`、数据库、管理员 token、SSH 私钥和
代理会话数据未进入版本控制。
