<h2 id="cn-v2.6.5">新增功能</h2>

- 对话名称自动跟随 Claude Code 或 Codex 的原生标题，手动命名可保留，也可以切回自动命名。
- 工作区支持按目录批量暂存，全部暂存入口在滚动时保持可见。

## 体验优化

- 从项目看板打开本地计划弹窗。列表支持搜索、筛选和分页，详情按需加载，查看计划时保留看板的位置。
- Issue 摘要按状态独立加载，历史记录由服务端分页；轮询失败时保留已有列表并提供重试。
- 阅读长对话时固定当前轮次的用户提问；工作区操作按钮更紧凑，Issue 的工作区详情可展开查看。

## 问题修复

- 修复过程页提前写入模块工作区导致开工失败，以及无关 SSH 登录阻塞工作区停止确认的问题。
- 取消任务后释放已停止且干净的工作区；保留有改动的现场并指出占用来源。

## 其他变更

- 生产发布由部署主机拉取固定标签构建，并通过备份和原子切换上线。

<h2 id="en-v2.6.5">New Features</h2>

- Conversation names follow native Claude Code or Codex titles. Keep a manual name or switch back to automatic naming.
- Stage changes by directory. The stage-all control stays visible while scrolling.

## Improvements

- Open local plans from the project board. Search, filter and page the list; load details on demand while preserving the board position.
- Load issue summaries by status and page historical records on the server. Keep existing results and offer retry when polling fails.
- Pin the user question for the conversation turn you are reading. Workspace controls are more compact, and issue workspace details can be expanded on demand.

## Bug Fixes

- Prevent early issue documents from blocking workspace preparation, and keep unrelated SSH logins from blocking workspace stop confirmation.
- Release clean workspaces after cancelled tasks have stopped. Preserve workspaces with changes and identify what is holding them.

## Chores

- Build the exact release tag on the deployment host, then switch production atomically after taking a backup.
