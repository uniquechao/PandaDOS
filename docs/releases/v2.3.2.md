# PandaDOS v2.3.2

## Highlights / 版本亮点

- **English:** Issue execution is now more deterministic from start to finish, with explicit pause and resume semantics, independent validation gates, and stronger completion recovery.<br>
  **中文：**Issue 执行从开始到结束更加确定，新增明确的暂停与恢复语义、独立验证门禁，以及更可靠的完成状态恢复。
- **English:** Modules can isolate their own execution context and mount governed skills, keeping agent behavior aligned with the work being performed.<br>
  **中文：**模块现在可以隔离各自的执行上下文并挂载受策略约束的技能，使 Agent 行为始终与当前工作保持一致。
- **English:** Agent activity is easier to follow through richer command and tool details, native-style event presentation, and remembered agent preferences.<br>
  **中文：**通过更丰富的命令与工具详情、更贴近原生体验的事件展示，以及可记忆的 Agent 偏好，Agent 活动更易于理解和追踪。

## New Features / 新功能

- **English:** New projects can initialize and maintain a Git repository automatically, reducing setup work before the first Issue runs.<br>
  **中文：**新项目可自动初始化并维护 Git 仓库，减少首次运行 Issue 前的准备工作。
- **English:** Issue execution supports an explicit paused state for stop-loss control, with clear guidance for resuming work safely.<br>
  **中文：**Issue 执行支持明确的暂停状态以便及时止损，并提供安全恢复工作的清晰指引。
- **English:** Agent selectors now display agent logos and remember the user’s previous choices.<br>
  **中文：**Agent 选择器现在会显示 Agent 标识，并记住用户上一次的选择。

## Improvements / 改进

- **English:** Validation runs independently from the Agent and can reuse existing evidence, improving consistency without repeating unnecessary work.<br>
  **中文：**验证流程独立于 Agent 运行，并可复用已有证据，在避免重复工作的同时提升一致性。
- **English:** Default reasoning levels have been tuned to reduce unnecessary compute while preserving appropriate depth for demanding work.<br>
  **中文：**默认推理等级已重新调整，在保留复杂任务所需深度的同时减少不必要的计算开销。
- **English:** The Issue toolbar is more compact, blocked states provide clearer explanations, and page titles identify PandaDOS and the active project more clearly.<br>
  **中文：**Issue 工具栏更加紧凑，阻塞状态的说明更加清晰，页面标题也能更明确地标识 PandaDOS 与当前项目。
- **English:** Ubuntu agent discovery, SSH first-connection handling, and Enter-key submission are more reliable across supported environments.<br>
  **中文：**Ubuntu 环境下的 Agent 发现、SSH 首次连接处理以及 Enter 键提交在各类受支持环境中更加可靠。

## Fixes / 修复

- **English:** Creating a new Issue no longer loses the Issue body during initialization.<br>
  **中文：**创建新 Issue 时不再在初始化过程中丢失正文内容。
- **English:** Resuming a blocked Issue continues the existing work instead of incorrectly starting it over.<br>
  **中文：**恢复被阻塞的 Issue 时会继续原有工作，不再错误地从头开始。
- **English:** Completed work is recovered and classified more reliably when an execution process exits unexpectedly.<br>
  **中文：**执行进程意外退出时，已完成的工作现在能够被更可靠地恢复并正确归类。
- **English:** Clarification flows no longer fail prematurely because of an overly short timeout.<br>
  **中文：**澄清流程不再因超时时间过短而提前失败。

## Upgrade Notes / 升级说明

- **English:** This release includes database migrations. Back up the PandaDOS database and runtime data, and stop active tasks before upgrading.<br>
  **中文：**本版本包含数据库迁移。升级前请备份 PandaDOS 数据库与运行数据，并停止正在执行的任务。
- **English:** After updating, run `bun install --frozen-lockfile`, `bun run check-i18n`, `bun run typecheck`, `bun test`, and `bun run build-ui`, then verify the `/healthz` endpoint.<br>
  **中文：**更新后请依次运行 `bun install --frozen-lockfile`、`bun run check-i18n`、`bun run typecheck`、`bun test` 和 `bun run build-ui`，随后检查 `/healthz` 接口。
