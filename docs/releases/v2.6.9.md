<h2 id="cn-v2.6.9">问题修复</h2>

- 修复大型仓库的 Git 文件清单被日志截断的问题，使原生集成可以完整读取待提交路径。
- 修复暂存历史已跟踪文件时遇到忽略规则而失败的问题。运行数据仍按既有规则排除。
- 修复手动恢复已确认停止的 Issue 时，会话归属校验失败的问题。未固定成果的任务可继续使用原工作区和会话。

<h2 id="en-v2.6.9">Bug Fixes</h2>

- Read complete Git file inventories during native integration in large repositories, without truncating paths to the log output limit.
- Fix staging failures caused by ignore rules on files that were already tracked. Runtime data remains excluded by the existing rules.
- Fix session ownership checks when manually resuming a confirmed-stopped issue. Issues whose results have not been finalized can continue in the existing workspace and session.
