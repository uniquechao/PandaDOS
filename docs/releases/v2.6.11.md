<h2 id="cn-v2.6.11">新增功能</h2>

- Issue 的 Worktree 页签支持查看合并进度、与独立合并 Agent 对话，以及手动接管和归还工作区。

## 体验优化

- 合并前先安装锁定的依赖，再记录验收输入。目标分支、源码或依赖变化时重新验证候选。推送中断后先核对远端结果，再决定是否继续。
- 合并面板读取超时时保留最近一次进展，并提示可以重试。

## 问题修复

- 工具生成的缓存不再使验证结果失效。真实输入变化会触发重新准备和验证，并保留失效原因与剩余的合并修复次数。

## 其他变更

- 根据执行机的实际剩余磁盘空间和 inode 预留工作区容量。

<h2 id="en-v2.6.11">New Features</h2>

- The issue Worktree tab shows merge progress, supports chat with a dedicated merge agent, and lets users take over and hand back the workspace.

## Improvements

- Install locked dependencies before recording validation inputs. Revalidate the candidate when the target branch, source files, or dependencies change. After an interrupted push, check the remote result before deciding whether to continue.
- Preserve the last known progress when the merge panel times out and show that the request can be retried.

## Bug Fixes

- Tool-generated caches no longer invalidate validation results. Actual input changes trigger preparation and revalidation while preserving the reason for invalidation and the remaining merge repair attempts.

## Chores

- Reserve workspace capacity based on available disk space and inodes on the executor.
