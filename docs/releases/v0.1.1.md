# MandoAI v0.1.1

## English

### Highlights

- Unified the product brand and runtime identifiers as MandoAI / `mando` / `MANDO_*` / `~/.mando`.
- Added application-wide localization for 10 languages, with English as the default and final fallback language.
- Added automatic locale and IANA time zone detection on first visit, plus user-selectable language and time zone preferences that persist across sessions.

### New Features

- Added a language switcher to the sign-in page, with interactions optimized for both desktop and mobile devices.
- The AI butler now selects Chinese or English prompts based on the user's language; clarifications, summaries, and approval explanations use the user's selected language.
- Notifications, confirmation cards, and business summaries are rendered per recipient using that recipient's language and time zone.
- Added internationalization safeguards for ICU message formatting, plural rules, pseudolocalization, catalog consistency, and visible-text scanning.

### Improvements

- Added English-first documentation with matching Simplified Chinese versions for the README, deployment guide, execution model, and internationalization contribution guide.
- User-authored issues, code, paths, commands, terminal output, Git content, and existing chat history remain in their original language to preserve technical meaning.
- Added a one-time migration tool for safely moving legacy runtime directories and identifiers to the MandoAI naming scheme.

### Fixes

- Completed long-tail interface, validation, error, and notification translations that previously fell back to English in some non-English locales.
- Fixed notification summaries being composed too early in a fixed language, preventing per-recipient localization.
- Fixed inconsistent native-control styling and behavior in the sign-in page language menu.

### Upgrade Notes

- Back up the database and runtime directory, and stop active tasks before upgrading.
- Use `MANDO_*` environment variables, `~/.mando` as the runtime data directory, and `mando` as the systemd service name.
- Run the legacy-directory migration tool in dry-run mode first, review the plan, and then apply it. The migration preserves source data and supports idempotent retries.
- After upgrading, run `bun run check-i18n`, `bun run typecheck`, `bun test`, and `bun run build-ui`, then verify `/healthz`.

## 简体中文

### 版本亮点

- 产品品牌与运行时技术标识统一为 MandoAI / `mando` / `MANDO_*` / `~/.mando`。
- 全站国际化覆盖 10 种语言，英语作为默认语言和最终回退语言。
- 首次访问可按浏览器地区与 IANA 时区自动匹配；用户可随时切换并持久保存语言及时区偏好。

### 新功能

- 登录页提供语言切换入口，并针对桌面端和移动端优化交互。
- AI 管家按用户语言选择中文或英文提示词，澄清、摘要和审批说明使用用户选择的语言。
- 通知、确认卡片和业务摘要在发送时按每位收件人的语言及时区分别渲染。
- 新增 ICU 消息格式、复数规则、伪本地化、目录一致性和可见文字扫描等国际化护栏。

### 改进

- README、部署指南、执行模型和国际化贡献指南均提供英文主文档及简体中文对应版本。
- 用户输入的 issue、代码、路径、命令、终端输出、Git 内容和已有聊天记录继续保持原文，避免技术语义失真。
- 新增一次性迁移工具，将旧运行目录与技术标识安全迁移到 MandoAI 命名体系。

### 修复

- 修复部分非英语界面回退为英文的问题，并补齐长尾界面、校验、错误和通知文案。
- 修复通知摘要在业务层预先拼接固定语言、无法按收件人偏好渲染的问题。
- 修复登录页语言菜单的原生控件样式和交互不一致问题。

### 升级说明

- 升级前请备份数据库和运行目录，并停止正在执行的任务。
- 环境变量统一使用 `MANDO_*`，运行数据目录统一为 `~/.mando`，systemd 服务名使用 `mando`。
- 旧目录迁移应先使用迁移工具的 dry-run 模式核对计划，再执行 apply；迁移过程保留源数据并支持幂等重试。
- 升级后运行 `bun run check-i18n`、`bun run typecheck`、`bun test` 和 `bun run build-ui`，随后检查 `/healthz`。
