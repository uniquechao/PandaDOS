<h2 id="cn-v2.6.6">新增功能</h2>

- PM 根据工作区、会话和验证进展监督普通模块 Issue，在停滞时按需干预。
- 独立合并 Agent 可在原候选工作区修复冲突或验证失败。修复后重新执行候选验证。

## 体验优化

- 执行恢复沿用原工作区、分支和已有进度，并保留历史会话。人工暂停与待答澄清继续由用户处理。

## 问题修复

- 停止详情显示当前轮次的具体原因、下一步和分支不匹配信息，方便判断如何恢复。

## 其他变更

- 持久保存监督决策、恢复记录和合并修复状态，重启后沿用已有进度和重试预算。

<h2 id="en-v2.6.6">New Features</h2>

- A PM supervises regular module issues using workspace, conversation, and validation progress, and intervenes when execution stalls.
- A separate merge agent repairs conflicts or validation failures in the existing candidate workspace. The candidate is validated again after repair.

## Improvements

- Recovery resumes the existing workspace, branch, and progress, and preserves conversation history. Manual pauses and unanswered clarifications remain under user control.

## Bug Fixes

- Stop details show the current attempt's specific cause, next step, and branch mismatch information.

## Chores

- Persist supervision decisions, recovery records, and merge repair state so progress and retry budgets survive restarts.
