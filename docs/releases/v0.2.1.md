# PandaDOS v0.2.1

## 版本亮点

- 受阻任务改为由用户填写补充意见或解除方法后恢复规划，避免直接重复原执行路径。
- 中英文 README 启用全新的 PandaDOS 横版品牌头图。

## 新功能

- 受阻状态下可编辑 Issue、当前受阻子任务及后续未完成子任务；保存编辑不会自动重跑，确认解除后才进入恢复规划。
- 恢复流程会把最新 Issue 内容、子任务快照和用户提供的解除方法一并交给规划阶段。

## 改进

- 恢复弹窗展示受阻原因并校验解除方法，补齐十种语言的界面文案。
- 通用弹窗完善模态语义、首次聚焦、Escape 关闭和 Tab 焦点约束，并优化窄屏、触屏及减弱动效体验。

## 修复

- 修复“解除堵塞”直接重跑受阻任务、无法提供新处理方法的问题。
- 清理并永久忽略发布中间目录，避免临时公开副本触发品牌静态门禁。

## 升级说明

- 本版本无需数据迁移。升级后建议运行 `bun install --frozen-lockfile`、`bun run check-i18n`、`bun run typecheck`、`bun test` 和 `bun run build-ui`，再重启服务并检查 `/healthz`。
