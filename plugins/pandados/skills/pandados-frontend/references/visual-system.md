## 组件契约

| 元素 | 必须保持 |
| --- | --- |
| Logo 与侧栏 | PandaDOS 标识居左；展开侧栏显示图标与文字，收起时保留同一组线性图标和可访问标签。当前导航使用浅黄底与黄/深色文字。 |
| 按钮 | 主按钮为黄底深字，次按钮为暖白底细边框，三级按钮以文字承载低优先级操作；图标按钮与文字按钮需有默认、悬停、按下、禁用与焦点状态。 |
| 搜索与表单 | 输入高度约 40px，1px `--pd-border`、10px 圆角、左侧搜索/字段图标；占位文本次要，焦点使用黄环。不要只靠占位文字说明字段。 |
| 标签与状态 | 使用柔和浅色胶囊，文本明确状态；如 `进行中`、`完成`、`已取消`，不要只用色点。 |
| 卡片与列表 | 暖白卡片、细边框、12px 圆角、24px 内边距、12px 组件间距；标题、内容、元信息按清晰层级排列。 |
| 图标 | 使用约 1.5px、圆端圆角的线性图标；同一界面只使用一个图标家族。图标不替代文字标签或无障碍名称。 |
| 助手面板 | 约 320px 宽、16px 圆角、浅黄对话气泡、逐项快捷操作和底部输入框；让其辅助主任务，不遮挡主内容。 |
| 终端横幅 | 深色近黑底、等宽字、琥珀色线路与 PandaDOS 标识；作为状态/品牌横幅，约 120px 高、24px 内边距，避免抢占主内容。 |

## 动效与反馈

### Motion Token

```css
--motion-instant: 80ms;
--motion-fast: 140ms;
--motion-base: 220ms;
--motion-slow: 320ms;
--motion-panel: 420ms;
--ease-standard: cubic-bezier(0.2, 0, 0, 1);
--ease-enter: cubic-bezier(0, 0, 0.2, 1);
--ease-exit: cubic-bezier(0.4, 0, 1, 1);
--ease-emphasized: cubic-bezier(0.2, 0.8, 0.2, 1);
```

- Hover 使用 140ms；按下使用 80–120ms；Chip/Tag 状态使用 180ms；卡片展开使用 220–320ms；Drawer/Modal 和页面切换使用 320–420ms。
- 页面进入为 `opacity: 0 → 1`、`translateY(8px) → 0`、320ms；顶部、主卡、列表、辅助面板按 30–50ms 间隔分层进入，不做明显瀑布。
- 页面切换时旧页 `opacity: 1 → 0`、`Y: 0 → -4px`，新页 `opacity: 0 → 1`、`Y: 8px → 0`，总时长 280–360ms；不做整屏左右滑动。
- 骨架屏使用浅米白/暖灰流光，周期 1.4–1.8s，透明度 `0.35 → 0.7 → 0.35`，圆角与真实内容一致。
- 按钮 Hover 为 `translateY(-1px)`、亮度 +4% 与轻微增强阴影，不得放大超过 1.01；Press 为 `scale(0.98)` 且 Y 轴回到 0，不弹跳。
- 按钮 Loading 时原文案淡出，显示 14–16px Spinner，宽度不变并禁止重复点击；Spinner 以 800–1000ms 线性旋转。
- Success 从 Spinner 切到 Check，`scale: 0.8 → 1`、`opacity: 0 → 1`、180ms，保持 600–900ms 后恢复原文案。
- Disabled 统一 `opacity: 0.45`、`cursor: not-allowed`，禁止任何 Hover 和 Press 动效。
- 侧栏、面板和卡片的进入/退出应保留空间连续性；加载状态应立即给出确定的骨架或文本反馈。
- 为 `prefers-reduced-motion: reduce` 关闭非必要位移与循环动效；状态仍须直接可理解，不得依赖动效。
- 不以悬停作为唯一操作入口；将 Hover 规则放在 `@media (hover: hover)` 内，触控设备同样能完成全部操作。

## 可访问性

- 正文与背景满足至少 WCAG AA 对比度；浅黄底上的文字通常使用 `--pd-text`，不要用低对比度黄字。
- 所有交互控件都可通过键盘到达、激活并显示焦点；图标按钮提供可读名称。
- 可操作区域优先达到 44px 触控目标；当视觉控件保持 40px 时，以足够的无重叠点击区补足。
- 保持标题层级、表单标签、错误说明和状态提示的语义关联；不要只用颜色、位置或动效传递信息。

## 应做 / 不应做

| Do | Don't |
| --- | --- |
| 用暖白留白、细边框和柔和阴影建立层次。 | 不用深色大面积背景或厚重投影制造“科技感”。 |
| 用黄色突出一个主要操作和当前状态。 | 不在一屏内堆叠多个同权重的黄色主按钮。 |
| 保持 4px 间距节奏、统一圆角与线性图标。 | 不混用不同图标风格、任意圆角和不规律间距。 |
| 用卡片、标签和元信息组织可扫描的任务状态。 | 不把信息架构改成仅凭装饰的海报式排版。 |
| 以短促、可关闭或可减弱的动效反馈状态。 | 不使用循环闪烁、夸张弹跳、自动播放或干扰阅读的动效。 |
| 保留现有功能、导航与用户原始文本。 | 不因参考图中的生成文案而改写产品内容、删改字段或重排功能。 |
